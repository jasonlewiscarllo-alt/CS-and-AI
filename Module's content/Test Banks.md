### Answer Key: True/False

1. **True.** RAM requires power to maintain its state (volatile). *(Hardware)*

4. **True.** With *n* lines, 2^n addresses can be reached. 2^32 bytes = 4 GB. *(Hardware)*
5. **False.** An interrupt causes the processor to suspend its current task, save its state, run the ISR, and then restore state to continue. It does not restart the computer. *(Hardware)*
6. **False.** It is the other way around. DRAM uses capacitors that leak charge and requires periodic refresh. SRAM uses multiple transistors and does not need refresh while powered. *(Hardware)*
7. **True.** Routers operate at the network layer, connecting different networks and forwarding packets based on IP addresses. *(Networks)*
8. **False.** TCP is connection-oriented and ensures reliable, in-order delivery. IP is the connectionless protocol. *(Networks)*
9. **False.** A star topology isolates failures. If one cable breaks, only that specific device is affected; the rest of the network keeps working. *(Networks)*
10. **False.** Simplex is one-way only. Half-duplex is both directions but not at the same time. *(Networks)*
11. **True.** Phishing relies on user action (clicking a link), while pharming uses DNS or browser manipulation to automatically redirect the user. *(Networks)*
12. **False.** RL is given no labels; it learns from trial and error and delayed reward signals. *(Behavioural AI)*
13. **True.** Q-learning uses the max operator to learn the optimal policy, even if it is behaving exploratorily (off-policy). *(Behavioural AI)*
14. **True.** The discount factor (γ) shrinks future rewards to reflect uncertainty and the preference for immediate rewards. *(Behavioural AI)*
15. **False.** Value iteration merges policy evaluation and improvement by immediately taking the best action at every state, using the Bellman optimality equation. *(Behavioural AI)*
16. **True.** This is the plain English translation of the Bellman equation. *(Behavioural AI)*
17. **False.** A positive TD error means the outcome was better than expected. A negative TD error means it was worse, so the actor should decrease the probability of that action. *(Behavioural AI)*
18. **False.** A CPU is optimized for low-latency sequential tasks (like running an OS), while a GPU is optimized for high-throughput parallel tasks. *(Hardware)*
19. **False.** A MAC address is a permanent physical identifier hardcoded into the NIC. An IP address is a logical address that can change. *(Networks)*
20. **True.** SARSA is on-policy; it updates using the action actually taken next (including exploratory moves). *(Behavioural AI)*

### Answer Key: Open-Ended

**41. [Hardware] Sample Answer & Key Points:**
*   **Key Points:** The OS divides memory into fixed-size blocks called pages. Virtual memory uses secondary storage (SSD/HDD) as a swap file. When a program requests a page not in RAM, a **page fault** occurs. The OS writes an unneeded page from RAM to the swap file and reads the required page into RAM. 
*   **Explanation:** This creates an illusion of larger memory, allowing programs larger than physical RAM to run. However, excessive swapping (thrashing) slows down the system drastically because secondary storage is much slower than RAM. *(Connects to Activity 1.8).*

**42. [Networks] Sample Answer & Key Points:**
*   **Key Points:** Packet switching breaks data into small packets, each with a header (source/destination IP, sequence number), payload (actual chunk of data), and trailer (error-checking bits). 
*   **Explanation:** Packets travel independently through available routes and may arrive out of order. The receiving device uses sequence numbers to reassemble them. This is efficient because many devices can share the network simultaneously. It is resilient because if a router or link fails, packets can be rerouted; if one packet is lost, only that small piece needs to be resent, rather than the whole file. *(Connects to Worked Example 1).*

**43. [Behavioural AI] Sample Answer & Key Points:**
*   **Example Reward:** +10 for on-time delivery, -20 for a crash, -1 per minute late, -0.1 per unit of energy used.
*   **Intended Behaviour:** The drone learns efficient, punctual delivery routes that conserve battery.
*   **Unintended Behaviour:** The drone might learn to fly dangerously fast or cut close to obstacles (near-misses) to save time, because the reward function only penalizes actual crashes, not risky flying. 
*   **Fix:** Add a proximity penalty (e.g., -5 for flying within 1 meter of an obstacle) to encourage safer flight paths. *(Connects to Activity 18.1).*

**44. [Behavioural AI] Sample Answer & Key Points:**
*   **Core Idea:** The value of a state is the immediate reward received for the next step, plus the discounted value of the state you land in.
*   **Calculation:** From (0,0), the agent can go Right or Up. 
    *   Right leads to (1,0) with reward 0. Q(Right) = 0 + 0.9 * V(1,0) = 0 + 0.9 * 1 = 0.9.
    *   Up leads to (0,1) with reward 0. Q(Up) = 0 + 0.9 * V(0,1) = 0 + 0.9 * 0 = 0.
*   **Conclusion:** The optimal action is Right. V*((0,0)) = max(0.9, 0) = 0.9. *(Connects to Section 7.4).*

**45. [Networks] Sample Answer & Key Points:**
*   **Between Buildings:** Mesh or Hybrid topology. A mesh provides multiple redundant paths, so if one link fails, data automatically reroutes through another path, ensuring high reliability across the city. A hybrid combining mesh between buildings and star inside is also excellent.
*   **Inside the Lab:** Star topology. Each computer connects independently to a central switch. If one computer or cable fails, only that specific node goes down, and the rest of the lab continues working. It also makes it easy to add or remove computers. *(Connects to Activity 2).*

**46. [Hardware] Sample Answer & Key Points:**
*   **Definitions:** An embedded system is a dedicated computer inside a larger device for a specific function. A monitoring system observes and reports (e.g., a thermometer). A control system observes and acts automatically (e.g., a thermostat turning on a heater).
*   **Smart Thermostat Example:** 
    *   **Sensor:** Measures the current room temperature.
    *   **Actuator:** The relay that turns the heater/AC on or off.
    *   **Feedback Loop:** The microcontroller compares the sensor reading to the target temperature. If it's too cold, it triggers the actuator to turn on the heater. As the room warms, the sensor updates the reading, and the system turns the heater off once the target is reached. *(Connects to Section 1.11).*
